** Ollama

- [[https://docs.ollama.com/cli][Ollama CLI reference]]
- [[https://huggingface.co/HuggingFaceTB/SmolLM2-135M][SmolLM2-135M]] from HuggingFace

*** Run a model locally

The Ollama server loads the model and generates replies. The Ollama
command-line client sends prompts to the server and displays its replies.

In a terminal, check whether the local server is already listening.

#+begin_src sh
curl -fsS http://127.0.0.1:11434/api/tags
#+end_src

A JSON response means the server is running, even if its list of models
is empty. If =curl= reports a connection failure, start the server in
that terminal and leave it running.

#+begin_src sh
ollama serve
#+end_src

In a second terminal, run =ollama list=. If =smollm2:135m= is missing
from the list, run =ollama pull smollm2:135m=. The downloaded model takes
about 270 MB of disk space ([[https://ollama.com/library/smollm2:135m][Ollama model listing]]).
Then start the interactive prompt.

#+begin_src sh
ollama run smollm2:135m
#+end_src

At the =>>>= prompt, try typing =Name one fruit.= and press Enter.
Once you see a reply, type =/bye= to return to the shell.

Run =ollama ps= shortly after the reply, while the server is still
running. Look at the =PROCESSOR= column for =smollm2:135m=. =100% GPU=
means the whole model was loaded into GPU memory, =100% CPU= means it
was loaded into system memory, and a split means Ollama uses both. If
the model has disappeared from the list, send another prompt and check
again. See the [[https://docs.ollama.com/faq#how-can-i-tell-if-my-model-was-loaded-onto-the-gpu][Ollama GPU FAQ]].

To inspect the model's configuration, run the following while the
server is still running.

#+begin_src sh
ollama show --modelfile smollm2:135m
#+end_src

*** Free memory and disk space

After leaving the chat with =/bye=, use =ollama ps= to see which models
are still loaded. To release the RAM or GPU memory immediately and keep
the download for next time, run =ollama stop smollm2:135m=. Run
=ollama ps= again to check that the model has been unloaded.

Before downloading a model, check its size in the Ollama model library.
Use =ollama list= to see the models on disk and their sizes. To reclaim
disk space, choose a model you no longer need and run =ollama rm= with
its exact name and tag. For example, =ollama rm smollm2:135m= removes
the model used in this exercise. Run =ollama list= again to check. You
can download it again later with =ollama pull=. See the
[[https://docs.ollama.com/cli][Ollama CLI reference]].

When you finish using Ollama, stop the server as well if you want it
out of the background. For a server you started with =ollama serve=,
press =Ctrl-C= in its terminal. If Ollama was already running, check
=systemctl is-active ollama=. If it reports =active= and you are done
using the service, run =sudo systemctl stop ollama=. Start it again
when needed with =sudo systemctl start ollama=. See the
[[https://docs.ollama.com/linux][Ollama Linux guide]].
